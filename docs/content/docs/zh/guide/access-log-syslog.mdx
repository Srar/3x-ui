---
title: 访问日志 syslog 投递
description: 将 Xray 实时访问日志投递到远程 syslog 接收端。
---

在 **Xray 设置 → 日志配置** 中启用访问日志文件，然后打开其下方的 **Syslog 投递**。开启后显示传输协议、接收服务器和端口。服务器可填写域名、IPv4 或 IPv6 地址，不包含端口或方括号；默认使用 UDP 和端口 514。

本页统一保存所有配置。首次开启或关闭投递时，会重启正在运行的 Xray；仅修改协议、服务器或端口不会重启 Xray。关闭投递后隐藏配置项，已填写的值保留。日志等级不能为 `none`。

访问事件经 Xray stdout 实时进入面板，分别写入原有本地文件并加入投递队列。投递不会读取历史 `access.log`。原有访问日志查看、每日清理及文件大小清理继续生效；syslog 只发送当前面板的 Xray 访问日志，DNS、错误日志和内部 API 调用不在投递范围。

消息使用 RFC 5424，facility/severity 为 `local0/info`，应用名 `3x-ui`，消息标识 `access`。TCP 接收端需支持 RFC 6587 字节长度分帧。正文为 JSON，字段为 `DateTime`（UTC）、`FromAddress`、`ToAddress`、`Inbound`、`Outbound`、`Email`、`Raw`。缺失时间为 `null`，缺失字符串为空，沿用 Xray 的日志脱敏设置。

接收端断线时自动重连。内存队列最多 4096 条、32 MiB，满时丢弃新记录；单条编码消息超过 60 KiB 时跳过。更换投递目标会清空旧队列，退出时最多等待 3 秒发送剩余消息。失败和丢弃会写入面板日志。UDP 无接收确认，TCP 写入成功也不代表接收端已持久化；该功能为尽力发送，可能丢失或重复，不提供历史补投、持久化队列或 TLS。

设置 API 的 `/panel/api/xray/` 返回独立的 `accessLogSyslog` 对象。`/panel/api/xray/update` 接受同名 JSON 字符串表单字段：

```json
{"enabled":true,"protocol":"tcp","host":"syslog.example.com","port":514}
```

该配置保存在面板设置中，不属于 Xray JSON 模板。旧客户端省略此字段时保留已有配置。
